# 固定图预测加速审计

## 范围

旧`aebad_s_fixed_target_graph_p0`及WITNESS模块不改动。新入口只绑定旧`prediction.freeze`的PreparedSearch与layer_branches图搜索依赖；FunctionType生成独立函数全局字典，不临时覆写旧模块全局变量。原始提取、Source/Target FP32检索、Top2 SEGMENT、缩距控制、两级MAD、CH1/CURRENT和评价接口保持原入口。三域及七分支不变。

## 保持搜索集合的工程调整

- 压紧的是已冻结三个图掩码的并集，保持原始边顺序，不新增或删除任一分支实际启用边。
- 节点仅取启用边的端点。输出胜边映射回父图原编号，后续代表佐证点和alpha来源不变。
- FP32输入保持原始数值，不作FP16/BF16量化或归一化。范数/边长/误差界标量/最终直接投影用FP64。
- 全局两遍扫描：先得到全局上界，再复核所有不能排除的候选。没有固定Top-k或按超时切换算法。

## 初筛误差与复核

维度d，FP32 epsilon，`gamma=(d+8)*eps/(1-(d+8)*eps)`。点积绝对误差以Cauchy的`||q|| ||x||`上界估计并乘保守系数；另计FP64范数误差与FP32下溢绝对项。FP32溢出不返回错误距离，区间变为不确定，交给直接FP64投影。

端点距离区间得到线段最小距离区间：对任意alpha∈[0,1]，端点扰动的加权和不超过两个端点误差的最大值；边长扰动至多乘alpha(1-alpha)≤1/4。额外保守计入FP64标量运算。每个分支跨所有启用边取最小上界，只有下界不大于该上界的候选才能成为最优值，全部直接复核，不随机挑选。

候选裁剪不改变最终直接投影公式；UNION精确平局保留UNION，边精确平局保留较小父编号。FP32平方差不作为正式距离。误差区间会影响复核量，真实数据中是否足够窄以及实际速度必须由GPU实测回答，不能从单次CPU测试推断加速倍数。

初筛局部关闭TF32/autocast，异常也恢复。此版本不宣称FP16 Tensor Core加速；未来若再引入TF32/FP16量化，必须另计输入截断误差，不能直接套本版本的FP32界。

默认preflight不加载Torch或CUDA，不写输出，不做容量门槛。smoke是同Q图搜索数值核对，沿用原距离atol=1e-7/rtol=1e-6并检查胜边，不是重做108图或96项LOO。全域预测冻结之后才进入GT评价。CPU评价、AUPRO和汇总调用旧实现，不新增近似指标。

续跑检查父冻结记录及新冻结选择/名单/MAD/代码；已完成图像逐图封存复用。部分写入产物保持原有拒绝行为，不重认改过的文件。旧资产实体应保留到新运行结束。
